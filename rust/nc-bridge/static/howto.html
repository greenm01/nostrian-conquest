How to play

Choose a sign-in method, claim a seat, and build your empire.

1. Sign in

Open the game list and choose Discord, Nostr or Matrix. Players using any of them can join the same game.

With Discord

Choose Sign in with Discord. Sign in to your Discord account and approve access. You’ll return to the game list.

With Nostr

Install nos2x for Chrome or Flamingo for Chrome. Set up your Nostr key in the extension, then reload the game list.

Enable only one Nostr extension at a time. If you have others installed, disable them and reload the game list before signing in.

Choose Sign in with Nostr and approve the request in your extension. You can enter a player name before signing in. Your private key stays in the extension; don’t paste it into the game.

With Matrix

Choose Sign in with Matrix and sign in to your matrix.org account if asked. You’ll return to the game list. The game sees only your Matrix ID, never your messages or rooms. Your Matrix display name becomes your player name.

If your Matrix account is on another server, choose Matrix account not on matrix.org? instead and enter your Matrix ID, such as @you:example.org. Our bot, @nostrian-conquest-bot:matrix.org, invites you to a private room and sends a sign-in link and a code. Open the link in this browser, or enter the code on the game list. Each works once and expires after ten minutes.

2. Claim a seat

Find a recruiting game. If it asks for an invite code, contact the sysop for one. Enter the code and choose Join.

Each code works once. Your seat belongs to the Discord account, Nostr key or Matrix account you used to claim it. The same code cannot claim another seat or give a second identity access.

3. Play—and come back

Choose Play to open the game. Next time, sign in with the same Discord account, Nostr key or Matrix account. You won’t need another invite code.

A recruiting game lets you prepare while the host gathers players. It starts only when the host launches it. If another terminal is still open, choose Reconnect to close it before continuing.

For your first orders, read the Quick Start. The Player Manual covers the rules.
