**Welcome to Nostrian Conquest**

Build an empire, explore the galaxy, and conquer rival worlds. NC is a turn-based space strategy game with an old-school BBS interface. You play in your browser. No install needed.

**Join a game**
1. Type `/games` in this server to see the game list.
2. For an invite-only game, ask the host for a private code. Enter `/join`, choose the game, and enter your code. Example: `/join game:beta-1 code:YOURCODE`. Open games need no code.
3. Use `/play` with that game ID. Open the link and sign in with the same Discord account.
4. Name your empire and issue your orders.

Each code claims one empire. Keep it private. You only need it once; your Discord account owns the seat afterward.

You can also find games at https://play.nostrian-conquest.com.

**Take your time**
Log in when it suits you. Each game has its own turn schedule. Maintenance advances the game by one year and resolves your orders. Return afterward to read your reports and plan your next move. You do not need to stay online.

**Keep a map beside you**
Use `/map` to download a ZIP with TXT, CSV, ODS, and Excel files. Print the map or use a spreadsheet to track your plans. The download shows your empire's known information.

**Useful commands**
• `/status` — Check the game year and next turn.
• `/report` — Download your empire's reports.
• `/manuals` — Get the quick-start guide and full player manual.
• `/help` — See all bot commands.
• `/about` — Learn about NC.

Bot replies and empire downloads are visible only to you. Use the game ID from `/games` when a command asks for one.

Start with the quick-start guide. Ask in this server if you get stuck.
